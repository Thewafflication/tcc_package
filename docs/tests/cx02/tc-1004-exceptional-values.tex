\section*{TC-1004 Exceptional complex values}
\textbf{Requirements:} TCC-CX-REQ-1004.

Apply the CX2 decision table to positive and negative zero, infinity, and NaN
for projection, square root, exponential, logarithm, and representative
trigonometric/hyperbolic functions. Pass requires the specified component
classification and sign; floating-point exception flags are not asserted.

\section*{TC-1007 Complex debug types}
\textbf{Requirements:} TCC-CX-REQ-1007.

Compile global variables of all three complex precisions with DWARF enabled
and inspect the debug information. Pass requires complex-float base-type
encoding, correct byte sizes, standard names, and absence of anonymous
real/imaginary structure members for those variables.
